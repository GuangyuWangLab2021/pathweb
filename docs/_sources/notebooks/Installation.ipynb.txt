    "1. **Navigate to the Loki2 source directory and create a conda environment**:\n",
    "   ```bash\n",
    "   cd ./src\n",
    "   conda env create -f environment.yaml\n",
    "   conda activate loki2_env\n",
    "   ```\n",
    "\n",
    "2. **Install Loki2**:\n",
    "   ```bash\n",
    "   python -m pip install .\n",
    "   ```\n",
    "\n",
    "3. **(Morphology-to-transcriptome retrieval only) create the OmiCLIP environment**:\n",
    "\n",
    "   Transcriptome encoding is done with OmiCLIP, the visual-omics foundation model behind\n",
    "   [Loki](https://github.com/GuangyuWangLab2021/Loki) (Nature Methods). It ships its own\n",
    "   environment, `loki_env`, which is separate from `loki2_env` and is only needed for\n",
    "   `encode_trans.py`; every other step runs in `loki2_env`.\n",
    "\n",
    "   Follow the installation instructions of the [Loki repository](https://github.com/GuangyuWangLab2021/Loki):\n",
    "   ```bash\n",
    "   conda create -n loki_env python=3.9\n",
    "   conda activate loki_env\n",
    "   cd /path/to/Loki/src\n",
    "   python -m pip install .\n",
    "   ```\n",
    "\n",
    "   Then download the [OmiCLIP checkpoint](https://huggingface.co/WangGuangyuLab/Loki) `omiclip.pt` and place it in `./src/loki2/`."
