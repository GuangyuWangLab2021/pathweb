loki2.models.utils.blocks
=========================

.. py:module:: loki2.models.utils.blocks

.. autoapi-nested-parse::

   Building blocks for neural network architectures.

   This module provides reusable convolutional and deconvolutional blocks
   for use in segmentation networks.
