   Linear Classifier for cell type classification.

   A two-layer fully connected network with ReLU activation and optional
   dropout for classifying cells based on their embeddings.

   :param embed_dim: Embedding dimension (input dimension).
   :param hidden_dim: Hidden layer dimension. Defaults to 100.
   :param num_classes: Number of output classes. Defaults to 2.
   :param drop_rate: Dropout rate. Defaults to 0.
