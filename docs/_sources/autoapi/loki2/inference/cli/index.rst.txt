loki2.inference.cli
===================

.. py:module:: loki2.inference.cli

.. autoapi-nested-parse::

   CLI for Loki2 cell inference.

   This module provides command-line argument parsers for WSI inference
   operations, supporting both in-memory and disk-based processing.
