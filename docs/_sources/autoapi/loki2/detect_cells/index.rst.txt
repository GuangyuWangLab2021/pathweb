loki2.detect_cells
==================

.. py:module:: loki2.detect_cells

.. autoapi-nested-parse::

   Loki2 Inference Pipeline for Whole Slide Images (WSI) in Memory.

   This module provides the main entry point for cell detection and segmentation
   on whole slide images using the Loki2 model.







Module Contents
---------------

.. py:data:: current_dir

.. py:data:: project_root

.. py:function:: main() -> None

   Main entry point for cell detection on WSI files.

   Parses command-line arguments and processes either a single WSI file
   or a dataset of WSI files for cell detection and segmentation.

   :raises ValueError: If neither filelist nor wsi_folder is provided
       when processing a dataset.
