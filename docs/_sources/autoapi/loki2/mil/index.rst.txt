loki2.mil
=========

.. py:module:: loki2.mil

.. autoapi-nested-parse::

   Cell-level Multiple Instance Learning (MIL) module for Loki2 .

   This module provides functionality for training MIL models on cell embeddings
   to predict patient-level outcomes, including data preparation, model training,
   and evaluation utilities.
