loki2.mil.models.src.utils
==========================

.. py:module:: loki2.mil.models.src.utils

.. autoapi-nested-parse::

   Utility functions for MIL model evaluation and visualization.

   This module provides functions for calculating metrics, evaluating models,
   generating attention heatmaps, plotting training curves, and computing
   cross-validation results.

   Downsample data by patient and embedding counts.

   Reduces the dataset size by sampling patients and their embeddings
   according to specified ratios, while maintaining class balance.

   :param dataframe: Input DataFrame with columns: Patient_ID, Patient_Label,
                     and embedding features.
   :param negative_ratio: Ratio of negative patients to keep. Defaults to 1.0.
   :param positive_negative_ratio: Target ratio of positive to negative patients.
                                   Defaults to 1.0.
   :param max_patients: Maximum number of patients to keep. If None, no limit.
                        Defaults to None.
   :param embedding_ratio: Ratio of embeddings to keep per patient. Defaults to 1.0.
   :param random_seed: Random seed for reproducibility. Defaults to 27.

   :returns: Downsampled DataFrame with the same structure as input.
   :rtype: pd.DataFrame
