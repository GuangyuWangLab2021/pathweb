loki2.mil.prampt_generate.blca_stage_prampt
===========================================

.. py:module:: loki2.mil.prampt_generate.blca_stage_prampt

.. autoapi-nested-parse::

   Generate PRAMPT data for BLCA stage analysis.

   This script loads cell embeddings from .pt files, samples balanced subsets
   of cells by disease stage, and saves the merged embeddings as a parquet file
   for MIL training.
