loki2.mil.prampt_generate.blca_stage_prampt

Generate PRAMPT data for BLCA stage analysis.

This script loads cell embeddings from .pt files, samples balanced subsets of cells by disease stage, and saves the merged embeddings as a parquet file for MIL training.

Sets up dummy modules for ‘loki2’ and its submodules.

Loads and processes cell embeddings from .pt files, sampling a subset of cells based on sample_ratio, and appends to records list.

  • target_count – Target number of successfully processed samples.

  • stage_num – Stage number (0 or 1) for logging.

  • directory_path – Directory containing _cells.pt files.

  • stage_df – DataFrame with Disease_Stage information.

  • records – List to append processed DataFrames to.

  • sample_ratio – Ratio of cells to sample from each file. Defaults to 0.1.
